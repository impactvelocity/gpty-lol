ICQ pixel agent SVGs

12 individual 16 x 16 SVGs and one self-contained 128 x 96 SVG sprite sheet.
Sprite order: 4 columns x 3 rows, matching the supplied brief.
Each sheet cell is 32 x 32, with its 16 x 16 icon inset by 8 pixels.
All icon silhouettes end at local row 14 for a shared baseline.

Only integer-positioned 1 x 1 pixel rectangles are used for the artwork.
Each icon has four solid palette entries: the supplied body color, dark outer
outline, light inner top-left bevel and dark inner bottom-right bevel.
No faces, interior outlines, gradients, filters, shadows or background fills.
The empty area in every SVG is transparent.

Display individual icons at 16, 32, 48 or 64 CSS pixels for integer pixel scaling.
Use image-rendering: pixelated when embedding SVGs with an img element.
The SVGs also set shape-rendering="crispEdges".
Keep icon sizes and parent transforms on whole pixels. Avoid fractional scaling.

The sprite includes a named symbol for each agent and twelve use elements.
It can be used as a complete image; individual files are provided for the
simplest reliable contact-list usage. See manifest.json for cell coordinates.
